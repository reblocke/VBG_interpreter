Scope boundary

For research and education only

This implementation is not clinically validated, is not medical advice, and must not be used to diagnose, treat, or replace an arterial blood gas when arterial confirmation is required. It never estimates arterial oxygenation, tissue hypoxia, or oxygen extraction.

Client-side by design

Use synthetic values only

Calculations run in this browser. Values are not placed in the URL, stored locally, sent to analytics, or submitted to a calculation server. Loading the page and Python runtime makes ordinary same-origin hosting requests.

Inputs

Current venous gas and chemistry

Required source measurements are interpreted as entered. Optional information only enables the corresponding modeled or contextual lane.

Current venous blood gas

PvCO2 remains a measured venous value. It is never relabeled as PaCO2 or passed directly to arterial Boston logic.

Current chemistry

Serum total CO2 is retained as chemistry context; it is not silently treated as blood-gas bicarbonate.
